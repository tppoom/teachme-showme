Three ways to fix the handoff

Extend onboarding

Push the sequence from 30 to 90 days. Cheap, partial.

Pooled CSM

One team covering everything under 20 seats. Two hires.

In-product nudges

No headcount, but six weeks of engineering we don't have.

Only the middle one addresses the cause rather than the symptom.

Option one is what we will do regardless, so present it as a floor rather than a choice; on its own it is not sufficient. Option three is genuinely good but competes directly with the enterprise engineering work, which is the decision on the next slide.

Where the threshold lives

function assignCsm(account) {
  const seats = account.seats;
  if (seats < 20) return null;      // ← set in 2023, never revisited
  return pickOwner(account.region);
}

One line, one hard-coded constant, set three years ago. The fix is not technical at all, which is precisely why it has never been done — there is no ticket for it and no team that owns the threshold. That is the argument for assigning it to someone.
